# 워커 안전 금지 목록

다음 행동은 하지 않습니다.

- API 키, 토큰, 쿠키, 비밀번호, 개인 식별 정보의 값 읽기·출력·복사
- `.env` 원문을 프롬프트, 로그, 커밋, 외부 서비스에 전송
- 사용자의 실제 브라우저 데이터 디렉터리 또는 `Default`, `Profile N` 읽기·쓰기
- 사용자 프로필을 복사해 자동화에 사용
- 계정 생성, 결제, KYC, 세금·법률 동의, 명의 행위
- 승인되지 않은 외부 발송, 게시, 삭제, 구매
- 저장소 전체를 무차별 탐색하거나 작업 범위를 벗어난 파일 수정
- 같은 파일을 다른 워커와 동시에 수정
- 경고 문자열만으로 워커 실패·성공 판정
- 검증 exit code 없이 완료 선언

자동화 브라우저가 필요하면 전용 격리 프로필을 사용합니다.

```bash
--user-data-dir="$PWD/.automation-chrome"
```

필요한 자격 증명은 존재 여부만 `SET` 또는 `missing`으로 보고합니다. 사람만 수행해야 하는 단계는 `HUMAN_ACTION_REQUIRED`로 표시합니다. 위반 가능성을 발견하면 작업을 멈추고 파일·행동·차단 이유를 보고합니다.
